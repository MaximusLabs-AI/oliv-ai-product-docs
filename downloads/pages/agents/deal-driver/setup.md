# Set up Deal Driver

*V1 review draft · 2026-10-16 · Source-described scope; confirm workspace availability*

<a id="overview"></a>
## Overview

Plan Deal Driver inputs, process ownership, review controls and a representative acceptance exercise.

<a id="scope"></a>
## Choose the first task

Begin with one of the detailed task guides below. Agree the outcome and identify the source systems it requires.

- [Review the manager morning brief](morning-brief.md)
- [Triage event-triggered deal alerts](risk-alerts.md)
- [Review rep-level next-step nudges](rep-nudges.md)
- [Review an end-of-day pipeline recap](sunset-summary.md)
- [Prepare 1:1 and team pipeline reviews](weekly-manager-review.md)

<a id="connect"></a>
## Prepare inputs



1. Verify workspace entitlement and the current agent entry point with Oliv.
2. Connect the relevant CRM, calendar, recording, email or notification source with approved access.
3. Confirm account and user matching using representative data.
4. Document the process definitions, thresholds and output ownership needed for the first task.

<a id="review"></a>
## Start with human review

Require review of recommendations and external actions until the supported execution policy and permissions have been tested. A source describing automation is not enough to enable it for every action.

<a id="test"></a>
## Acceptance and recovery

Run one normal task and one case with missing, conflicting or restricted data. Inspect the source evidence and final result. If acceptance fails, stop external writes for that task and resolve the input, mapping or permission issue with its owner.

<a id="questions"></a>
## Agent-specific confirmation



- Confirm delivery channel, timing, time zone and whether multiple managers can share the same team.
- Confirm thresholds, deduplication, dismissal behavior and alert routing; published examples are not universal defaults.
- Confirm cadence, escalation, quiet hours and control over notification volume.
- The original reference leaves whether the recap is fully scheduled or prompt-driven unresolved across deployments.
- Confirm multi-manager and multi-territory behavior, exact delivery cadence and access boundaries.
