# Review an account research brief

*V1 review draft · 2026-10-16 · Source-described scope; confirm workspace availability*

<a id="overview"></a>
## Overview

Researcher describes company overview, funding context, news and market background for an upcoming first meeting.

<a id="prerequisites"></a>
## Before you begin

Use a workspace where the agent and required source connections have been enabled. Name the user responsible for review and verify access to the representative account, deal or recording.

- [Researcher agent](../researcher.md)
- [Agent configuration](../configuration.md)

<a id="procedure"></a>
## Review procedure



1. Verify company identity.
2. Inspect recency and sources.
3. Remove irrelevant background.
4. Choose meeting-relevant facts..

<a id="expected-result"></a>
## Expected result to verify

A concise account brief with reviewed public context. This is an acceptance target for the described workflow; record whether it actually occurs in the current deployment.

<a id="exceptions"></a>
## Exceptions and missing information

Confirm data providers, freshness, coverage and licensing; public facts can change.

If the result is absent or inconsistent, retain the source record, timestamps and the review decision. Verify connector health and permissions before repeating an action that could produce an external change.

<a id="acceptance-record"></a>
## Record acceptance



| Field | What to retain |
| --- | --- |

| Downstream result | Final CRM, email, report or configuration state, where applicable |
