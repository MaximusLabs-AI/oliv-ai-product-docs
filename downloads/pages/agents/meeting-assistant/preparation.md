# Review an existing-deal meeting brief

*V1 review draft · 2026-10-16 · Source-described scope; confirm workspace availability*

<a id="overview"></a>
## Overview

The described brief combines deal history, qualification gaps, stakeholder context and a suggested agenda for an existing opportunity.

<a id="prerequisites"></a>
## Before you begin

Use a workspace where the agent and required source connections have been enabled. Name the user responsible for review and verify access to the representative account, deal or recording.

- [Meeting Assistant agent](../meeting-assistant.md)
- [Agent configuration](../configuration.md)

<a id="procedure"></a>
## Review procedure



1. Verify meeting and opportunity association.
2. Review the last commitments.
3. Inspect missing qualification.
4. Adjust the agenda..

<a id="expected-result"></a>
## Expected result to verify

A prepared meeting agenda with source context. This is an acceptance target for the described workflow; record whether it actually occurs in the current deployment.

<a id="exceptions"></a>
## Exceptions and missing information

Brief timing varies across sources. Confirm trigger, time zone and delivery behavior instead of promising an exact lead time.

If the result is absent or inconsistent, retain the source record, timestamps and the review decision. Verify connector health and permissions before repeating an action that could produce an external change.
